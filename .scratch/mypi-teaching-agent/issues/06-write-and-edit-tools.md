# 06: `write` 与 `edit` 工具

**What to build:** agent 能把结论落到仓库里：整文件写入，以及按精确文本替换的编辑（支持一次提交多段互不重叠的编辑）。找不到目标文本、目标文本出现多次、编辑区间重叠时，都给出可恢复的错误结果供模型重试，而不是静默改错文件。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] agent 能创建新文件并写入指定内容，落盘结果逐字节符合预期
- [ ] 精确文本替换生效，文件其余部分保持不变
- [ ] 一次提交多段互不重叠的编辑全部生效
- [ ] 目标文本不存在时回灌错误结果，文件未被修改
- [ ] 目标文本出现多次时回灌错误结果（除非明确允许全部替换），文件未被修改
- [ ] 编辑区间重叠或多段编辑互相干扰时回灌错误结果
- [ ] 既有测试不改一行仍然全绿
