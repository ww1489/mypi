# 03: `read` 工具打通工具回灌闭环

**What to build:** agent 能根据模型请求读取文件，把内容作为工具结果回灌给模型，模型再基于文件内容给出回答——这是第一个真正闭环的 agent 行为（请求 → 工具 → 回灌 → 再请求）。读取结果按行数与字节数双阈值截断，并在截断时明确标注"已截断"及其原因，避免长文件塞爆上下文。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 模型请求读文件后，最终回答正确引用了文件内容
- [ ] 回灌的工具结果在录制载荷中与对应的工具调用 ID 正确配对
- [ ] 超过阈值的大文件被截断，输出中包含截断提示与截断位置信息
- [ ] 读取不存在的文件时得到明确的错误结果，而不是让整个 run 崩溃
- [ ] 既有测试不改一行仍然全绿
