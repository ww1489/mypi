# 11: 最小 TUI（加餐）

**What to build:** 一个全屏终端界面：消息块（用户 / 助手）、工具执行状态（进行中 / 完成 / 失败）、可滚动历史、多行输入。agent 事件与键盘输入在**同一个主循环**上派发，慢操作丢到后台完成后投递回主循环（不复刻 PiG 的完整终端能力协商，也不做 markdown 渲染与语法高亮）。退出后终端状态被正确还原。

**Blocked by:** 10

**Status:** ready-for-agent

- [ ] 全屏界面中可见用户消息、助手回答与工具执行状态块
- [ ] 流式回答的增量能被逐段渲染（不闪烁、不整屏重绘）
- [ ] 历史可上下滚动查看
- [ ] 输入支持多行编辑，Enter 与换行可区分
- [ ] agent 事件与按键处理在同一主循环上派发（无共享内存竞争）
- [ ] 退出后终端恢复原状（光标、回显、备用屏缓冲区）
- [ ] 既有测试不改一行仍然全绿
