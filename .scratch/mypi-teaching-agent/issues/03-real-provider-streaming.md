# 03: 真实 provider（deepseek + SSE 流式）

**What to build:** 把假 provider 换成真实模型：回答以增量形式逐段出现在 stdout，网络错误、超时、限流给出可读的错误信息并终止当前 run（而不是挂住）。密钥解析顺序为环境变量优先、回退到已有的 pig 配置（`~/.pig/agent/auth.json`），永不写入仓库或会话文件。假 provider 降级为测试专用，不再参与主路径。

本票还没有任何工具，所以只验收纯文本多轮对话。「流式工具调用参数拼接」与「含工具调用的真实对话」两条验收挪到票 04——那时有 `read` 工具，才验得动。
