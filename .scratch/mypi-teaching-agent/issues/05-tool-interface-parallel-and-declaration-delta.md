# 05: 工具接口演化到 PiG 形状（并发 + 声明增量）

**What to build:** 一次模型响应中的多个工具调用**并发执行**，但回灌的工具结果**严格按调用源顺序**排列——并发提速与确定性输出同时成立。工具声明不再是一张固定清单，而是以 system 消息增量的形式随请求下发（新增了哪些、移除了哪些），支持运行时改变可用工具集。参数不合法时以校验错误回灌而不是中断。任一工具声明为"串行"时，整批退化为串行执行。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 一次响应中的多个工具调用并发执行，总耗时明显小于逐个串行之和
- [ ] 工具结果消息顺序严格等于调用源顺序（与完成先后无关）
- [ ] 请求载荷中可见"新增工具/移除工具"的增量表达，而不是每次全量重述
- [ ] 运行时增删工具后，下一次请求的声明增量正确反映变化
- [ ] 参数不合法时回灌校验错误，模型可重试，run 不中断
- [ ] 混入一个串行工具后整批按串行执行，结果顺序仍正确
- [ ] 既有测试不改一行仍然全绿
