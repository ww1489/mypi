# 05: `bash` 工具与失败语义

**What to build:** agent 能执行 shell 命令并引用其输出（例如跑一次测试、看一眼目录结构）。命令带超时保护、不接管 stdin、输出超限时截断；**工具执行失败（非零退出、超时、命令不存在）作为错误结果回灌给模型**，整轮对话不中断，模型可以据此自行纠错。这是"工具失败不等于 agent 失败"这条契约的第一次落地。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] agent 执行一条命令并把 stdout 内容用于后续回答
- [ ] 命令超时后被终止，回灌结果标记为错误且含超时说明，run 继续
- [ ] 命令以非零退出码结束时，回灌结果标记为错误并包含退出码与 stderr 摘要
- [ ] 超长输出被截断并附截断提示
- [ ] 工具执行期间不读取、不占用 stdin（不会被交互式程序挂住）
- [ ] 既有测试不改一行仍然全绿
