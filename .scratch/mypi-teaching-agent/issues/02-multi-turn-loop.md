# 02: 多轮对话循环

**What to build:** 一次进程内可以连续多轮对话：交互式 REPL 与单次提问共用同一条循环，历史按顺序累积并随每次请求完整发出。第二轮请求里必须能看到第一轮的完整消息（用户消息与助手回复），证明上下文确实是累积的而不是各自独立提问。输入结束（EOF / Ctrl-D）时干净退出，不打印堆栈。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 同一次运行中连续三轮提问，第三轮请求的录制载荷包含前两轮的全部消息且顺序正确
- [ ] 单次提问模式与 REPL 模式共用同一循环实现（行为一致，仅输入来源不同）
- [ ] 关闭输入（EOF / Ctrl-D）后进程以退出码 0 结束且无 panic
- [ ] 消息的角色与内容结构可被解析回等价的内部表示（往返一致）
- [ ] 既有测试不改一行仍然全绿
