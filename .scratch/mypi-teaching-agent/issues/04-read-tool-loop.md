# 04: `read` 工具打通工具回灌闭环

**What to build:** agent 能根据模型请求读取文件，把内容作为工具结果回灌给模型，模型再基于文件内容给出回答——这是第一个真正闭环的 agent 行为（请求 → 工具 → 回灌 → 再请求）。读取结果按行数与字节数双阈值截断，并在截断时明确标注"已截断"及其原因，避免长文件塞爆上下文。

票 03 已接入真实模型，本票除了 faux 离线验收外，还要用真实模型把含工具调用的对话跑通；真实 provider 的流式工具调用参数拼接也在本票验收。

**本票同时要做的一次升级：** 把 `ContentBlock` 从扁平结构体（`Type` + `Text`）改成接口 + 多个具体类型（文本 / 工具调用），给 `Message` 增加工具结果消息，并把 system 提示从 `Request` 字段挪进消息数组（工具声明增量要挂在 system 消息上）。理由与切换时机见 `docs/compare/step-01.md`：只有出现第二种块之后，接口方案才能挡住"角色与块类型不匹配"这类错误。
