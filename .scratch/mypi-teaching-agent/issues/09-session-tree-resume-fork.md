# 09: 会话树：落盘、`--resume`、`--fork`

**What to build:** 会话自动落盘为**追加式 JSONL 树**：首行是会话头（版本、id、工作目录、时间），其后每行是一个带自身 id 与父节点 id 的条目，父指针构成树而非线性数组。可以直接用 `jq` 逐行读懂。`--resume` 恢复上次会话并继续对话（上下文正确重建）；`--fork` 从历史某一点分叉出独立分支，两条分支各自继续、互不污染，且都能再次 `--resume`。

**Blocked by:** 08

**Status:** ready-for-agent

- [ ] 会话文件首行为会话头，其后每行是独立 JSON，`jq` 可逐行解析
- [ ] 每个条目有唯一 id 与父节点 id，从任意条目可回溯到根
- [ ] `--resume` 后模型看到的上下文与中断前一致（录制载荷可验证）
- [ ] `--fork` 产生新分支，两条分支的后续消息各自独立，不会串到一起
- [ ] 分叉点之后的两条分支都能被再次 `--resume`
- [ ] 会话目录按项目路径区分，不同项目的会话不会混在一起
- [ ] 既有测试不改一行仍然全绿
